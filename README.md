## 配置示例

MRS（OISD / HaGeZi）

```yaml
rule-providers:
  hagezi-normal:
    type: http
    behavior: domain
    format: mrs
    url: https://cdn.jsdelivr.net/gh/haotzops/rules@release/hagezi/hagezi-normal.mrs
    path: ./rule-providers/hagezi-normal.mrs
    interval: 86400

rules:
  - RULE-SET,hagezi-normal,REJECT
```


TXT
```yaml
rule-providers:
  oisd-small:
    type: http
    behavior: domain
    format: text
    url: https://cdn.jsdelivr.net/gh/haotzops/rules@release/oisd/oisd-small.txt
    path: ./rule-providers/oisd-small.txt
    interval: 86400

rules:
  - RULE-SET,oisd-small,REJECT
```

YAML（OISD / HaGeZi）
```yaml
rule-providers:
  oisd-small:
    type: http
    behavior: domain
    format: yaml
    url: https://cdn.jsdelivr.net/gh/haotzops/rules@release/oisd/oisd-small.yaml
    path: ./rule-providers/oisd-small.yaml
    interval: 86400

rules:
  - RULE-SET,oisd-small,REJECT
```

sing-box 规则集：

```json
{
  "type": "remote",
  "tag": "oisd-small",
  "format": "binary",
  "url": "https://cdn.jsdelivr.net/gh/haotzops/rules@release/oisd/oisd-small.srs"
}
```

使用 `.json` 源文件时，将 `format` 改为 `source` 并将 URL 改为对应的 `.json` 文件。

## 格式说明：
- OISD 和 HaGeZi 均提供 `.txt`、Mihomo `.yaml`、`.mrs` 以及 sing-box `.json`、`.srs` 五种格式；`.txt` 使用 `format: text`，`.yaml` 使用 `format: yaml`，`.mrs` 使用 `format: mrs`；
- `.mrs` 由 CI 使用 `mihomo convert-ruleset domain yaml` 从对应的 `.yaml` 生成；`.json` 和 `.srs` 由 `meta-rules-converter` 从对应的 `.yaml` 生成。
