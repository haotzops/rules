## 配置示例

你只需要其中一个规则

MRS

```yaml
rule-providers:
  oisd-small:
    type: http
    behavior: domain
    format: mrs
    url: https://cdn.jsdelivr.net/gh/haotzops/rules@release/oisd/oisd-small.mrs
    path: ./rule-providers/oisd-small.mrs
    interval: 86400

  hagezi-normal:
    type: http
    behavior: domain
    format: mrs
    url: https://cdn.jsdelivr.net/gh/haotzops/rules@release/hagezi/hagezi-normal.mrs
    path: ./rule-providers/hagezi-normal.mrs
    interval: 86400

rules:
  - RULE-SET,oisd-small,REJECT
  - RULE-SET,hagezi-normal,REJECT
```

YAML
```yaml
rule-providers:
  oisd-small:
    type: http
    behavior: domain
    format: yaml
    url: https://cdn.jsdelivr.net/gh/haotzops/rules@release/oisd/oisd-small.yaml
    path: ./rule-providers/oisd-small.yaml
    interval: 86400

rules:
  - RULE-SET,oisd-small,REJECT
```
